# 🌌 NEXORA - AI-Powered Social Media Platform

## 🎯 Overview

NEXORA is a **production-ready, world-class social media platform** designed to compete with Instagram, Facebook, X, Discord, and VK while introducing **unique AI-powered experiences**.

### Key Features:
- 🤖 **AI-Powered** (NEX AI Assistant, Content Generation, Recommendations)
- 🔐 **Enterprise Security** (2FA, Device Management, Threat Detection)
- 🎨 **Cyberpunk Design** (Dark Fantasy, Premium UI, 3D Animations)
- 📱 **Mobile-First** (Responsive, Cross-Platform)
- ⚡ **Real-time** (Socket.IO, WebSockets)
- 📊 **Advanced Analytics** (DAU, MAU, Engagement Tracking)
- 👑 **Admin Dashboard** (Professional Management Tools)
- 🌍 **Scalable** (Millions of Users, CDN Ready)

## 🚀 Quick Start

### Prerequisites
- Node.js 18+
- Docker & Docker Compose
- PostgreSQL 14+
- Redis 7+

### Installation

```bash
# Clone repository
git clone https://github.com/bodyamir/Dark_Man.git
cd Dark_Man

# Setup environment variables
cp .env.example .env.local

# Start with Docker Compose
docker-compose up -d
```

### Accessing the Platform

- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:3001
- **Admin Dashboard**: http://localhost:3002
- **PostgreSQL**: localhost:5432
- **Redis**: localhost:6379
